# EcomWithShah Portfolio

React + Vite + TypeScript portfolio website.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Upload to GitHub

Upload the **contents of this ZIP** to the root of your repository (not the enclosing folder). Keep `index.html`, `package.json`, `src/`, and `public/` at the repository root.

## Deploy on Vercel

Import the GitHub repository. Framework: **Vite**. Build command: `npm run build`. Output directory: `dist`. Root directory: `./`.

The repository includes local videos in `public/videos/`; make sure they are uploaded too.
